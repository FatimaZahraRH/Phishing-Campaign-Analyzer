# Données (simulées)

| Fichier | Contenu |
|---|---|
| `employees.csv` | 1 200 employés pseudonymisés : service, groupe (formation / témoin). |
| `events.csv` | 9 600 envois (1 200 × 8 campagnes) : clic, saisie, signalement, délais en minutes. |

Générées par `python scripts/simulate.py` (graine fixe). Modèle et paramètres :
[`docs/simulation.md`](../docs/simulation.md). Ce sont des données fictives :
aucune personne réelle.

Pour analyser des données réelles, fournir ces deux fichiers au même format.
