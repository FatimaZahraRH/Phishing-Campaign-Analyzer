# C'était un exercice

Ce message faisait partie d'un exercice de sensibilisation de l'équipe Sécurité. Aucune donnée n'a été transmise, et personne n'est jugé : ces e-mails sont conçus pour être crédibles.

**Thème :** Alerte de sécurité sur le compte de messagerie

## Les indices que l'on pouvait repérer

- **Erreurs** : faute d'orthographe dans l'objet, faute de grammaire dans le texte
- **Indices techniques** : domaine d'expéditeur externe, lien vers un domaine inconnu, adresse de réponse différente
- **Présentation** : logo de faible qualité, mise en page différente de l'original
- **Langage et contenu** : formule générique (« Cher utilisateur »), demande inhabituelle
- **Ressorts de manipulation** : urgence, menace de conséquence, promesse de gain

## Le bon réflexe

1. Au moindre doute, cliquez sur **Signaler**.
2. Si vous avez saisi un mot de passe, prévenez l'équipe Sécurité : pas de reproche, on agit juste plus vite.
3. Vérifiez par un autre canal (téléphone, intranet) toute demande inhabituelle.
